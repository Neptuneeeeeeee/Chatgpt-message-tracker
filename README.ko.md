# ChatGPT Message Tracker

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · **한국어** · [Español](README.es.md) · [Français](README.fr.md)

ChatGPT 웹사이트에서 **내가 보낸** 메시지 수를 모드별(`Instant`, `Medium`, `High`, `Extra High`, `Pro`)로 기록하는 로컬 Chrome 확장 프로그램입니다. 실제 사용량을 언제든 정확히 확인할 수 있습니다.

> **독립적인 로컬 카운터입니다. OpenAI와 무관하며 OpenAI의 승인을 받지 않았습니다.**
> 공식 할당량을 조회하거나 남은 양을 예측하지 않으며, OpenAI 공식 사용량 데이터도 제공하지 않습니다.

## 설치

빌드가 필요 없습니다. 이 저장소에서 바로 로드하면 됩니다.

1. 이 저장소를 클론하거나 다운로드합니다(zip이면 압축 해제).
2. Chrome에서 `chrome://extensions/`로 이동합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축 해제된 확장 프로그램 로드**를 클릭하고 프로젝트 루트 폴더(`manifest.json`이 있는 폴더)를 선택합니다.
5. [https://chatgpt.com/](https://chatgpt.com/)을 열거나 새로고침하면 페이지 오른쪽 아래에 플로팅 카운터가 나타납니다.

## 사용 방법

1. **평소처럼 메시지를 보내기만 하면 됩니다.** 전송 시 입력창 옆에서 선택된 모드를 읽고, 메시지가 실제로 대화에 표시되면 해당 모드에 `+1`을 기록합니다.
2. **페이지의 플로팅 카운터**를 보거나 확장 프로그램 아이콘을 클릭해 팝업을 열면 모드별 집계, `+1`, **실행 취소**를 사용할 수 있습니다.
3. **잘못된 기록은 언제든 수정.** 누락이나 중복은 `+1`, 실행 취소, 최근 기록 삭제로 바로잡을 수 있습니다.
4. **자동 감지가 정확하지 않으면** 팝업에서 **모드 자동 감지**를 끄고, 수동으로 선택한 모드에 집계하세요.
5. **설정 페이지에서는 더 많은 기능을**: 모드 이름 변경, 사용자 지정 모드 추가, 기간별·일별 통계 보기, JSON내보내기, 기록 삭제.

다음 동작은 잘못 집계되지 **않습니다**: IME 후보 확정 Enter, 답변 생성 중 Enter, 초안 지우기, 답변 중지.

## 기능

- 모드별 전송 메시지 집계: `Instant`, `Medium`, `High`, `Extra High`, `Pro` 및 사용자 지정 모드.
- ChatGPT 페이지에 직접 표시되는 플로팅 카운터.
- 전송 순간의 모드 자동 감지. ChatGPT 페이지 자체의 언어와 라벨을 기준으로 하며 브라우저 언어로 추측하지 않습니다.
- 확장 프로그램 인터페이스는 21개 언어를 지원하며 브라우저 언어를 자동으로 따릅니다.
- 기간별 통계(최근 3시간 / 24시간 / 7일 / 30일)와 모드별 일별 통계.
- 수동 수정: `+1`, 실행 취소, 최근 기록 삭제.
- 설정과 사용 기록을 JSON으로내보내기.
- 모든 데이터는 Chrome 로컬 확장 프로그램 저장소에만 보관됩니다.

## 개인정보

이 확장 프로그램은 데이터를 업로드하지 않으며 대화 내용도 저장하지 않습니다. 전송 확인과 중복 집계 방지를 위해 페이지 메모리에서 초안과 새 메시지를 일시적으로 비교하며, 페이지를 닫으면 이 임시 상태는 사라집니다. 저장되는 각 기록에는 다음만 포함됩니다.

- 모드 ID
- 타임스탬프
- 기록 출처(전송 버튼, Enter 키, 수동 입력)

자세한 내용은 전체 [개인정보 처리방침](PRIVACY.md)을 참조하세요.

## 제한 사항

- 확장 프로그램이 설치된 Chrome 프로필에서만 동작합니다.
- ChatGPT 웹사이트에서 보낸 메시지만 집계합니다. 모바일 앱, 다른 브라우저, 다른 기기는 제외됩니다.
- 자동 감지는 ChatGPT 페이지 UI에 의존하므로, ChatGPT의 UI 변경 시 선택자 업데이트가 필요할 수 있습니다.
- 개인용 로컬 카운터이며 OpenAI 공식 사용량 측정 도구가 아닙니다.

## 업데이트

새 코드를 가져오거나 수정한 후에는 `chrome://extensions/`로 이동해 **ChatGPT Message Tracker** 카드의 새로고침 버튼을 클릭합니다.

## 개발

```sh
npm ci            # 의존성 설치
npm run check     # 정적 검사
npm test          # 단위 테스트
npm run test:chrome   # 격리된 Chrome 프로필에 실제 확장 프로그램을 로드해 로컬 테스트 페이지로 검증
```

모드 라벨 인식에는 21개 언어/지역 변형의 근거 데이터가 포함되어 있습니다. 출처, 원본 메시지 키, SHA-256은 `docs/site-language-evidence.json`에 기록되어 있습니다. 재검증 명령:

```sh
node --expose-gc tools/verify-evidence.mjs /path/to/exported-official-assets
```

## Chrome Web Store 패키징

```sh
npm ci
npm run check
npm test
python3 tools/build_release.py
```

스크립트는 업로드 가능한 확장 프로그램 zip과 `publish-kit.zip`(게시자 자료, **업로드 금지**)을 `dist/`에 생성합니다. `store/` 폴더에는 스토어 소개 문구, 권한/개인정보 작성 안내, 실제 UI 스크린샷이 있습니다. 전체 체크리스트는 `store/PUBLISHING.md`를 참조하세요.
