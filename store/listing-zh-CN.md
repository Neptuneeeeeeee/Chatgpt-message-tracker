# Chrome Web Store 中文商店文案

## 名称

ChatGPT Message Tracker

## 简短说明

按模式记录 ChatGPT 网页发送次数；本地保存历史，兼容多种 ChatGPT 界面语言。

## 详细说明（可复制）

想知道自己在 ChatGPT 网页里用了多少次不同模式？ChatGPT Message Tracker 帮你记录每次发送，并按模式查看计数、近期用量和每日记录。

主要功能：
- 按 Instant、Medium、High、Extra High 和 Pro 分别计数。
- 页面浮窗与工具栏弹窗，随时查看本轮发送次数。
- 支持手动选择模式、手动加一、撤销和删除记录。
- 查看近期统计、每日统计，并将设置和计数导出为 JSON。
- 基于 ChatGPT 页面自身语言和官方前端资源词条识别模式，而不是翻译你的提问内容。

识别词表包含 21 个语言／地区变体：英语，简体中文、台湾繁体中文、香港繁体中文，西班牙和拉美西班牙语，巴西和葡萄牙葡萄牙语，法国和加拿大法语，以及德语、日语、韩语、阿拉伯语、印地语、俄语、印尼语、意大利语、土耳其语、越南语和泰语。这里指 ChatGPT 页面标签的识别兼容；本扩展自身的按钮和设置目前以简体中文显示，模式名称可编辑。

隐私：计数与设置保存在当前浏览器的本地扩展存储中。为了判断消息是否真正发出，扩展在当前网页内存中临时比对输入框草稿与新出现的用户消息，并观察相关模式控件、会话路径和发送事件；不将对话正文保存到扩展存储，不上传给开发者或外部 AI 服务。没有广告、遥测和云同步，不需要提供 API key。

使用边界：
- 这是独立的个人计数器，不是 OpenAI 官方用量统计，不显示或保证剩余额度，也不能绕过任何限制。
- 只统计安装了本扩展的 Chrome 配置中的 ChatGPT 网页发送；不包含手机 App、其他设备、其他浏览器或安装之前的历史用量。
- ChatGPT 的账户类型、页面结构和服务器下发标签可能不同；无法确认的标签会使用明确标示的手动模式。部分词条来自官方网页其他设置模块，不能保证所有账户上的每个模式都能自动识别。
- 页面先出现用户消息不等于服务端最终成功计费。统计不用于账单或官方配额判断。
- 需要 Chrome 桌面版以及你自己的 ChatGPT 使用权限；本扩展不提供 ChatGPT 账户或订阅。
