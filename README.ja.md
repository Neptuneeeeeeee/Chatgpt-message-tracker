# ChatGPT Message Tracker

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語** · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md)

ChatGPT ウェブサイトで**自分が送信した**メッセージ数をモード別（`Instant`、`Medium`、`High`、`Extra High`、`Pro`）に記録するローカル Chrome 拡張機能です。実際の使用量をいつでも把握できます。

> **独立したローカルカウンターです。OpenAI とは一切関係なく、OpenAI の承認も受けていません。**
> 公式のクォータ照会、残量の予測、OpenAI 公式の利用データの提供は行いません。

## インストール

ビルドは不要です。このリポジトリから直接読み込めます。

1. このリポジトリをクローンまたはダウンロードします（zip の場合は展開）。
2. Chrome で `chrome://extensions/` を開きます。
3. 右上の**デベロッパーモード**をオンにします。
4. **パッケージ化されていない拡張機能を読み込む**をクリックし、プロジェクトのルートフォルダ（`manifest.json` があるフォルダ）を選択します。
5. [https://chatgpt.com/](https://chatgpt.com/) を開くか更新すると、ページ右下にフローティングカウンターが表示されます。

## 使い方

1. **いつも通りメッセージを送るだけ。** 送信時に入力欄の横で選択されているモードを読み取り、メッセージが実際に会話へ表示されてから、そのモードに `+1` を記録します。
2. **ページ上のフローティングカウンター**を見るか、拡張機能アイコンをクリックしてポップアップを開くと、モード別のカウント、`+1`、**元に戻す**が使えます。
3. **記録ミスはいつでも修正。** 取りこぼしや重複は `+1`、元に戻す、最近の記録の削除で修正できます。
4. **自動検出が合わない場合**は、ポップアップで**モードを自動検出**をオフにし、手動で選んだモードで集計できます。
5. **設定ページではさらに**：モード名の変更、カスタムモードの追加、期間別・日別統計の表示、JSON エクスポート、記録の消去ができます。

次の操作は誤ってカウントされ**ません**：IME の変換確定の Enter、回答生成中の Enter、下書きの消去、回答の停止。

## 機能

- 送信メッセージをモード別に集計：`Instant`、`Medium`、`High`、`Extra High`、`Pro`、およびカスタムモード。
- ChatGPT ページに直接表示されるフローティングカウンター。
- 送信の瞬間にモードを自動検出。ChatGPT ページ自体の言語とラベルに基づくため、ブラウザーの言語から推測しません。
- 拡張機能のインターフェースは 21 言語に対応し、ブラウザーの言語に自動で追従します。
- 期間別統計（過去 3 時間 / 24 時間 / 7 日間 / 30 日間）とモードごとの日別統計。
- 手動修正：`+1`、元に戻す、最近の記録の削除。
- 設定と利用記録を JSON でエクスポート。
- すべてのデータは Chrome のローカル拡張機能ストレージにのみ保存されます。

## プライバシー

この拡張機能はデータを一切アップロードせず、会話内容も保存しません。送信の確認と二重カウント防止のため、ページのメモリ内で下書きと新しいメッセージを一時的に比較しますが、ページを閉じるとこれらの一時状態は消えます。保存される各記録に含まれるのは次の 3 点だけです。

- モード ID
- タイムスタンプ
- 記録の来源（送信ボタン、Enter キー、手動記録）

詳しくは[プライバシーポリシー](PRIVACY.md)をご覧ください。

## 制限事項

- 拡張機能をインストールした Chrome プロファイルでのみ動作します。
- ChatGPT ウェブサイトで送信したメッセージのみを集計します。モバイルアプリ、他のブラウザー、他のデバイスは対象外です。
- 自動検出は ChatGPT ページの UI に依存するため、ChatGPT 側の UI 変更によりセレクターの更新が必要になる場合があります。
- 個人用のローカルカウンターであり、OpenAI 公式の利用量メーターではありません。

## 更新

新しいコードを取得または変更したら、`chrome://extensions/` を開き、**ChatGPT Message Tracker** カードの再読み込みボタンをクリックします。

## 開発

```sh
npm ci            # 依存関係をインストール
npm run check     # 静的チェック
npm test          # ユニットテスト
npm run test:chrome   # 隔離された Chrome プロファイルで実際の拡張機能を読み込み、ローカルのテストページで検証
```

モードラベルの認識には 21 の言語・地域バリアントの根拠データが同梱されています。出典、元のメッセージキー、SHA-256 は `docs/site-language-evidence.json` に記録されています。再検証は次のコマンドで行えます。

```sh
node --expose-gc tools/verify-evidence.mjs /path/to/exported-official-assets
```

## Chrome Web Store 用パッケージング

```sh
npm ci
npm run check
npm test
python3 tools/build_release.py
```

スクリプトはアップロード可能な拡張機能 zip と `publish-kit.zip`（公開者向け資料。**アップロードしないでください**）を `dist/` に出力します。`store/` フォルダにはストア掲載文、権限・プライバシー記入説明、実際の UI スクリーンショットが含まれます。完全なチェックリストは `store/PUBLISHING.md` を参照してください。
