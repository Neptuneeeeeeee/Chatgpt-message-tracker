# 0.4.0 手动测试清单

## 安装更新

已有加载项目根目录版本：在 chrome://extensions/ 中刷新原来的扩展，再刷新 ChatGPT 页面。不要卸载旧扩展，也不要另外加载 dist 中的一份同时使用，以免形成两个扩展实例和两套存储。

首次测试：解压 `chatgpt-message-tracker-0.4.0-chrome-web-store.zip`，在 chrome://extensions/ 开启开发者模式，加载含 manifest.json 的解压目录。

## 默认设置与切换入口

初次使用、或从旧版本升级且没有语言设置时，界面语言和模式选项语言均为 English。已有自定义模式名不会被翻译或覆盖。

点击扩展弹窗右上角 **Settings**，在页面顶部的 **Languages** 中设置：

- **Interface language**：浮窗、弹窗、设置页、确认提示、日期和计数格式的语言。
- **ChatGPT mode-label language**：本扩展的模式下拉项、模式计数卡片和历史模式名称的显示语言。

两个选项独立保存，更改后自动生效，无须再按 Save settings。模式名称编辑、增删和启用状态仍用 Save settings 保存。第二项不会修改 ChatGPT 网页设置或账户语言，也不会强制检测语言；网页计数始终使用实际 ChatGPT 页面信号。

## 建议手动验收

| 界面语言 | 模式选项语言 | 检查 |
| --- | --- | --- |
| English | English | 默认全部英文，模式 Instant / Medium / High / Extra High / Pro。 |
| 简体中文 | English | 按钮说明是中文，模式名称继续英文。 |
| English | 简体中文 | 按钮说明是英文，模式名称为官方词表的即时／中／高／极高／Pro。 |
| 简体中文 | 繁體中文（台灣） | 模式名称用即時／中／高／極高／Pro。 |
| العربية | English | 界面布局从右到左，模式名称仍是英文，不挤压或遮挡按钮。 |
| Deutsch / हिन्दी | 日本語 | 长文本可换行，模式名称仍是日文词表。 |

重新打开设置页、扩展弹窗和 ChatGPT 页面，确认语言选择还在。进入 More features，检查时间范围、每日统计、最近记录、日期以及删除按钮提示都随界面语言变化。

在同一个 ChatGPT 账户中选择一个可用模式，发送一条测试消息，应仅增加一次并记在正确模式下。改变插件的两种显示语言后再发一条，同一模式应连续累加；还应核对切换 ChatGPT 网页自身语言后的识别。

连续发送两次相同文字应分别计数；输入法选字、停止生成、打开历史会话不应加一。可用 +1 / Undo 修正自己的测试记录。

自定义一个模式名字并保存，再切换两种语言，名字应保留。只改语言不应增删历史，不应改变模式 ID。

## 发布包

本次上传包在 `dist/0.4.0/chatgpt-message-tracker-0.4.0-chrome-web-store.zip`。旧版0.3.0包保留在其原目录，不要混用。上传商店前请使用0.4.0的实际截图及更新介绍；本次修改不自动提交商店，也不发布远端版本。

界面译文已本地化并通过键完整性、占位符和渲染检查，但并非所有语言都经过母语者校对。模式词表保持原始官方资源，不把界面译文用于网页模式识别。真实账户可能仍因页面/服务器标签差异进入手动回退。
