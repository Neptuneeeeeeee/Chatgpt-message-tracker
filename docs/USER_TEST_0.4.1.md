# 0.4.1 手动测试清单

0.4.1 只修复计数：适配 ChatGPT 2026 年 9 月的新网页界面，并按官方当前语言资源补全模式词表。界面、设置项、权限和存储格式与 0.4.0 相同，0.4.0 清单中的语言设置检查仍然适用。

## 安装更新

已有加载项目根目录版本：在 chrome://extensions/ 中刷新原来的扩展，再刷新 ChatGPT 页面。不要同时启用商店版和本地加载版。

## 新界面上的计数

在自己的已登录 ChatGPT 网页中：

| 操作 | 预期 |
| --- | --- |
| 在已有会话里输入一条消息并按回车 | 只加一，记在输入框右侧显示的模式下。 |
| 再输入一条并点发送按钮 | 再加一；同一会话连续发送每条都计数。 |
| 从首页新建会话发送第一条 | 加一，模式是首页当时选中的那一档。 |
| 生成过程中点“停止”，或输入框为空时按回车 | 不加一。 |
| 点“编辑消息”后取消 | 不加一。 |
| 在几个已打开的会话之间来回切换，或向上滚动再回到底部 | 不加一；切换后浮窗显示当前会话自己的模式。 |
| 把思考强度依次调到五档 | 浮窗的当前模式随之变化。 |

“编辑消息后重新发送”不计数，与之前版本一致。窗口较窄时右下角浮窗可能盖住发送按钮，可先折叠浮窗。

## 已完成的实测（2026-09-30）

以上各项已在一个已登录账户的新界面上逐项实测通过。另在 21 个界面语言下读取了五档模式在输入框上的实际显示文字，全部能识别到对应模式；这些文字已写入单元测试。其他账户的服务器下发标签可能不同，无法识别时仍回退到手动模式。
